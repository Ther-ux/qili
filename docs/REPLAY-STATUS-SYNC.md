# v0.2.10 界面状态与核验同步

日期：2026-10-22。

## 摆谱调用反馈

训练页和导入页向逐步讲解器传入同一套全局调用状态更新方法。点击摆谱分析时显示“调用中”，响应后显示成功、带一致性提醒的成功或失败；顶部、全局反馈和 API 设置内的状态保持一致。

分析期间仍可自由走棋。旧局面的请求结束后，会更新调用结束状态，但不把旧结果写到新棋盘上；手动排队的新请求继续显示等待状态。已退出或已销毁的讲解器不会写回旧分析。终局只返回本地规则判定时，显示“本地分析完成”及“本次未调用模型”，不伪称模型调用成功。

## 回放核验

主线、其他走法、对方应对、走前／走后及摆谱局面统一通知报告区当前真实 FEN。报告底部据此重新计算并展示：

- 回放位置。
- 当前行棋方。
- 当前行棋方的合法走法数。
- 将军、对局进行中或终局胜负判定。

原始 E／S 编号资料保留在单独折叠区，标题注明“不随回放切换”。不会用模型原文替代本地规则判定，也不修改作答棋盘或学习成绩。核验区字号与对比度同步提高。

## 当前题目提示

换题、重试或连续将杀进入下一局面后，清空旧报告与核验信息。已配置 Key 时显示“当前局面尚未生成 AI 讲解”；未配置时说明本地功能无需 Key。辅助作答标记仍按原有规则保留，不因切换回放或模型失败而改写成绩。
