## 修复

1. DeepSeek 官方接口显式发送 `thinking: {type: 'disabled'}`，短讲解使用 `response_format: {type: 'json_object'}`、`max_tokens: 1024`。其他兼容接口不强行发送 DeepSeek 专属 thinking 字段。
2. 单独处理 finish_reason 为 length 的响应，明确标记截断并回退完整教案，不接受被截断结果。
3. 自然语言可以比较本题候选和引擎实际提供的合法着法。引擎着法在加入允许集合前再经规则核验；结构化作答字段仍须等于本题候选。没有放开任意着法。
4. 新增回归测试，覆盖“允许引用合法引擎对比、无工具来源则拒绝、不能替换本题答案、非法工具着法不能获准”。

依据：[DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)、[JSON 输出](https://api-docs.deepseek.com/guides/json_mode/)。
