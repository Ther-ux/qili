# v0.2.7 刷新与残局草稿恢复

旧版页面只在内存保留导入局面；HTTP 连接断开后，后端仍等待 DS，模型占用要等请求返回才释放。刷新同时造成丢失前台内容与后台忙碌，用户无法取得旧响应。

模型操作现在归属于对应 HTTP 响应。响应提前关闭或请求中断时，后端通过 AbortController 中断上游调用并释放占用。每次操作持有独立身份；已经取消的旧操作稍后结束不会清除新请求的占用。等待引擎时取消也会阻止后续模型调用。连接、定位、识图、题库、导入、摆谱和对照请求共用这套管理，并保留各阶段超时与整个操作的截止时间。截止时间也能释放未能及时返回的工作。客户端 pagehide 显式中断当前请求，不自动重新调用。

残局草稿通过本标签页的 sessionStorage 暂存，包括校正棋盘 FEN、未应用的 FEN 文本、行棋方、原图方向、图片及已确定的四角、确认状态、搜索范围、选中参考步、已完成的分析和 DS 讲解。刷新后直接恢复，不调用接口，不把旧的 pending/busy 状态恢复成新请求，也不会生成本地模板讲解。API Key、访问口令、请求 headers 和 modelSettings 不写入草稿；恢复后仍需重新应用 Key。图片重新识别仍须按原流程授权发送。

暂存失败时页面会说明：图片及完整分析放不下时优先保留棋盘；存储完全不可用时提示复制 FEN 或导出。缓存损坏不阻止打开页面。关闭标签页通常清除本次会话，浏览器也可能恢复会话；长期保存仍需导出。此版本没有暂存自由摆谱的当前分支和未返回的 DS 内容。旧版刷新前从未保存过的数据不能由这次更新恢复；已有 FEN 可以重新导入。

2026-10-22：Windows 自动检查包括真实本机 HTTP 断开后的上游 signal 中断、占用释放和手动重试，等待引擎时断开不再调用模型，旧操作不能释放新操作，占用截止时间与监听清理，提前断开不产生未处理异常。jsdom 检查完成后及执行中刷新能恢复残局与选步，不自动调用 API，页面 Key 不恢复，清空棋盘不会复活旧分析；另测损坏缓存、存储不足和嵌套凭据剔除。模型使用 mock，不产生真实 DS 费用。
