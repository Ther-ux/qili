# v0.2.9 解法回放与调用状态修复

日期：2026-10-22。

## 修改范围

1. “参考着法”按钮改为“查看本地解法”，报告标题为“本地解法回放”。本地提示和回放无需 Key，详细教学仍由 DS 提供；错误提示不再声称有完整离线教案。
2. 本地解法增加独立只读棋盘、步骤选择、前后定位、走前／走后切换和可点击线路。回放不修改练习棋盘或训练成绩，从当前局面进入摆谱并退出后保留回放位置。
3. 成功输出带一致性提醒时，顶部状态、页面调用状态与 API 设置中的状态均为“调用成功（有提醒）”，使用黄色提示，不再错误显示为“未测试”。
4. 对照结果分别展示两组提醒明细；整体状态按成功、带提醒成功或部分失败区分，不用固定的旧校验文案覆盖实际结果。
5. AI 请求失败不自动显示本地答案，也不新增辅助标记。已经用过提示或本地答案的尝试，失败后仍保留原辅助标记，不会反过来变成独立完成。

原教学提示词与 v0.2.8 的内容提醒策略未改变。可回放线路仍由本地工具提供，不采纳模型正文中新提出的着法。
