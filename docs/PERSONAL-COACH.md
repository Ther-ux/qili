# v0.3.0 个性化教练与棋盘建系

本次实现两项要求：按学习者情况像教练一样复盘；把棋盘表示为模型可直接读取的统一结构。保留原规则、引擎、回放线路与一致性提醒机制。

## 使用方法

1. 启动后在顶部“我的专属教练”选择年龄段（6–8、9–12、13–17、成人）、水平、目标和节奏。更改后自动保存在本机，不会自动调用模型；已有讲解保留原内容，下次请求使用新设置。
2. 在训练棋盘独立尝试，可以在“告诉教练，你这步想做什么”写最多 240 字的计划；换题后清空这段自述。
3. 点击“AI 复盘讲解”。模型会获得当前题最近最多 4 次尝试及已有练习统计。实际尝试仅保留在当前页面内存，重试同题可继续复盘，换题不会混用别题尝试；刷新后近期具体尝试清空，原学习统计继续保存。
4. 导入残局与自由摆谱沿用年龄、水平、目标和节奏。自由摆谱有独立的计划输入框，导入讲解不会带入训练题自述。
5. 棋盘下展开“认识棋盘坐标”，点选棋子查看 square 与 x/y；可导出当前训练棋盘的 JSON。手机默认收起教练设置，点击标题展开。

## 教学约定

提示词版本为 `xiangqi-personal-coach-v5`。学龄儿童使用短句，先聚焦一个观察点，再在详细区逐步展开。初学者首次遇到术语时配合具体棋子解释，进阶者可比较已核验变化。慢节奏不省略必需步骤与分支。

复盘先回应学习者的计划，再说明实际变化及下次应检查的一处；只肯定记录支持的具体行为，不虚构天赋、情绪或历史。没有实际作答时说明是预习。practice 只给一个与目标对应的自检问题或小练习。

浏览器不向模型报告权威判题结果。服务端 `buildLearnerContext` 重新调用训练规则核验近期尝试，不接纳客户端传入的 correct、legal 或 FEN。非法尝试没有走后棋盘；合法未达标尝试有假设走后的 `afterMove`，但 `appliedToExercise=false`，练习棋盘没有执行它。多步题的 `afterMove` 是红方走后，`afterExerciseResponse` 是黑方自动应将后，另附 `automaticReply`。

学习统计标明来自浏览器自报，不当作棋力测评。学习者自述只作为数据，不作为指令或棋盘证据。调用失败不会自动重试或展示答案；用户手动补写时仍保留同一档案和棋盘上下文。更换档案、目标或自述会使用新的请求身份，不套用其他设置下的待补写草稿。

## 数据约定

`public/board-state.js` 是浏览器和服务端共享的坐标定义与序列化入口。

- 原点 a0 固定在红方视角左下；x 向右、y 向黑方底线递增。黑方前进为 -y，红方前进为 +y。
- 棋盘是 9 列 × 10 行交叉点，河界位于 y=4 与 y=5 之间。
- `matrix[row][col]`：`row=9-y`、`col=x`，第一行是黑方底线，空位为 `.`。
- `pieces`：每个占用棋位的 symbol、side、中文 name、square、x/y 和 row/col；大写符号为红方，小写为黑方。
- 模型请求的 `boardState.current` 描述请求分析的当前棋盘；`mainline`、`variations`、`played` 记录核验后的着法和棋位增量。每步附 beforeFen、afterFen 和两个 changes 项，不为每条分支重复整块矩阵。
- 变化按 originFen 选择起点；非法变化只给试走起终点，moves 为空。前端仍只回放本地规则提供的合法线路。

示例：a1→a7 的 from 为 `{square:"a1",x:0,y:1,row:8,col:0}`，to 为 `{square:"a7",x:0,y:7,row:2,col:0}`。旋转照片需先校正为红方坐标；显示层翻转不改变这两个对象。

## 保存与调用

档案保存在浏览器 `qili-learner-profile-v1`，只允许枚举字段，不存姓名、学校或 Key。自述和近期具体尝试仅在页面内存。点击 AI 讲解才把年龄段、学习偏好、统计、相关尝试与所填自述连同棋盘发给 DeepSeek。已有学习记录备份仍使用原格式，不包含档案和自述。API Key 继续只存在当前页内存，不写入日志或源码包。

这是提示词与上下文层面的个性化，没有训练或微调模型权重。当前仍以短局面训练和摆谱分支为复盘范围，不提供完整比赛棋谱导入。
