# 页面 API 设置与验收

日期：2026-10-22。本轮只修改本地程序，未部署、发布博客或推送 GitHub；现有 `.env` 内容未修改。

## 使用方法

1. 启动程序，点击页面右上角 **API 设置**。
2. 在 **API Key** 输入框粘贴自己的 DeepSeek API Key。
3. 选择模型，默认 **deepseek-flash**，也可选择 **deepseek-v4-pro**。
4. 点击 **应用并测试连接**，等待明确的成功或失败提示。测试会向所选模型发送一次短请求，可能产生费用。
5. 关闭设置面板，点击 **AI 复盘讲解**。页面顶部和讲解按钮旁会显示调用中、调用成功或调用失败及原因。

仅点击“应用设置”不会发起模型请求，也不会被标为连接成功。测试连接检查模型确实能返回非空短文本；讲解仍独立检查 JSON 结构、候选着法和引用编号，两者不是同一种验收。

当前只支持页面手动输入，已移除“密钥来源”和“.env 配置”选项。每次刷新或重新打开页面都必须重新输入 Key；同一页面内连续使用无需重复填写。页面所选模型会传入本次调用，默认始终是 deepseek-flash。旧环境变量 `LLM_API_KEY`、`LLM_MODEL`、`LLM_BASE_URL` 不再参与模型请求。

## 状态反馈

| 场景 | 页面反馈 |
| --- | --- |
| 仅应用设置 | 已应用，尚未测试 |
| 连接测试正在请求 | 黄色等待状态，暂时禁用重复提交 |
| 连接成功 | 绿色成功状态、模型名、耗时 |
| 密钥无效或无权限 | 明确显示 API Key 无效、已过期或无权限 |
| 余额不足、模型不存在、限流 | 对应的中文原因，不回显服务商原始错误体 |
| 网络错误、超时、无效响应 | 明确失败，按钮恢复可用 |
| 讲解通过校验 | 调用成功、模型名、耗时，显示真实讲解 |
| 讲解内容被截断或未通过校验 | 调用失败，明确展示教案回退，不伪装成 AI 成功 |
| 新调用失败 | 隐藏旧 AI 结果，避免把上一条成功输出当作当前结果 |
| 空密钥直接应用 | 本地设置失败，不发送请求 |

## 密钥与请求边界

- 页面密钥只保存在当前页面内存，不写入 localStorage、sessionStorage、Cookie、学习记录或 `.env`。
- 密钥输入框为 password，应用后立即清空输入框显示；当前会话密钥仍在内存中，供后续主动调用。
- 点击清除、刷新或关闭页面都会移除页面密钥。清除按钮同时停用本页模型调用。
- 即使服务器环境里保留旧密钥，页面启动时也不会启用模型调用；后端拒绝无页面 Key 的请求和旧服务器密钥模式。
- 每次请求携带自己的配置，不改进程全局环境或共享密钥，不会将甲用户的密钥用于乙用户。
- 空白或无效的页面密钥不会回退使用其他密钥。
- 页面密钥只发送到固定的 DeepSeek 官方接口，不接受页面传入的第三方地址；拒绝重定向。
- 页面密钥只允许在本机回环地址或 HTTPS 页面使用，避免在普通远程 HTTP 页面中传输密钥。
- 公开部署仍需配置 HTTPS、项目访问控制与调用预算；本轮未上线。

模型选项依据 [DeepSeek 官方模型文档](https://api-docs.deepseek.com/api/list-models/)。本轮真实调用使用 deepseek-flash；pro 的页面选择、参数传递通过浏览器和 mock 测试检查，没有为验证选择器而调用 pro。
